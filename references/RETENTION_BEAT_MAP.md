# Case-adaptive 120s attention beat map — v2.7.0

**Fifteen 8-second render units are NOT fifteen mandatory story events.** Never invent a scan, test result, extra doctor, diagnosis or treatment merely to fill this table. The durations are container units; editor cuts within a unit are optional if they do not alter source meaning or approved identity.

| Clip | Absolute interval (FLOW_8S) | Suggested story function (conditional, never assumed real) |
|---|---|---|
| C01 | 0–8s | Clinical-safe hook in 0–3s; start the relevant real situation by 3–8s |
| C02 | 8–16s | Orient: who is affected, clinically supported symptom/problem |
| C03 | 16–24s | Source-supported chronology or current functional consequence |
| C04 | 24–32s | Clarify documented severity/uncertainty or meaningful observation |
| C05 | 32–40s | Relevant history/choice; omit absent consultations |
| C06 | 40–48s | First meaningful new true clue or question |
| C07 | 48–56s | Source-grounded context; reduce repeated exposition |
| C08 | 56–64s | Another supported perspective/scene, not an invented test |
| C09 | 64–72s | Clinician reasoning, if actual case supports and screenplay needs it |
| C10 | 72–80s | Explain a clinically relevant distinction or limitation |
| C11 | 80–88s | Integrate available evidence without premature diagnosis |
| C12 | 88–96s | Qualify differential/unknown or actual reported result |
| C13 | 96–104s | Fulfill main narrative question; do not delay urgent warning |
| C14 | 104–112s | Explain verified clinical teaching/outcome, if known |
| C15 | 112–120s | Clear source-faithful takeaway, uncertainty and attribution/disclaimer in budget |

This chart is an adaptable example. **Reassign every beat** to the case's supported events; do not force patient→doctor ordering, all named phases, a diagnosis or a death. If case lacks enough substance for 120 seconds, mark `NEEDS_SOURCE_FOR_SUBSTANTIVE_DRAMA / HOLD` or propose a shorter truthful teaching film.

## Prepublish pacing and trust check

- Does the opening promise match the final learning? If diagnosis is unknown, is that made clear rather than concealed?
- Does any beat add an invented investigation to create a cliffhanger? If so, remove it.
- Are all clinically consequential spoken AND visible claims mapped? Did Humanizer edit any source quotation? Re-audit.
- Does any static shot repeat information without purposeful context or understandable emotion? Consider a source-supported alternate shot or shorten/rebalance with actual duration math.
- Are all 0–8s C01, neighboring cuts, audio bridge and closing 8s coherent with the full sequence?
- Did editor-added captions/titles alter clinical certainty? Compare exact script and reviewed source.
- Does a proposed 9:16 reframing preserve face, hands, clinician/patient relationships, important anatomy and legible Bengali caption safe zone? If not, create a separate approved vertical composition or HOLD. This is optional; STYLE01 16:9 master remains canon.
- No timing/engagement claim without observing output metrics. Passing a paper beat map is planning, not measured completion/virality.
